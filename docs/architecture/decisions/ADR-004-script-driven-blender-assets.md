# ADR-004: script-driven Blender assets

## Status

Accepted.

## Context

Agents cannot drive the Blender UI. Assets must be reproducible from the
repository, and arena visuals must match arena collision.

## Decision

Assets are generated by Blender Python scripts run headless from the repo.
Arena visuals are generated from the same JSON the sim uses for collision.
Generated models are committed.

Alternative rejected: hand modelling in the Blender UI. It is not reproducible
by agents. It is allowed later for an art pass, but script-first remains the
rule.

## Consequences

- Blender is only needed locally. CI validates the committed `.glb` files with
  a script that uses only the Python standard library.
- Arena JSON is the single source for collision and visuals.
- Placeholder art fatigue is accepted. Script-first assets can be refined
  without changing the pipeline.
